## Featured Projects

### [Collaborator AI](https://github.com/sunjinwoo1298/CollabAI)
Real-time collaborative platform for designing software architecture, with an AI agent that edits the shared canvas alongside the team. [Live demo](https://collab-ai-beige.vercel.app)

- Conflict-free multi-user editing using Yjs CRDTs over a custom WebSocket server, with no third-party real-time service.
- Redis Pub/Sub backplane so multiple server instances stay in sync.
- Background AI design agent (Trigger.dev, Vercel AI SDK, Gemini) that applies validated, atomic changes to the canvas.
- Idempotent chat pipeline, Clerk authentication, project-level roles and signed short-lived room tokens.
- **Stack:** Next.js, TypeScript, Yjs, WebSockets, Redis, PostgreSQL, Prisma

### [EstateFlow AI](https://github.com/sunjinwoo1298/RealEstate)
Lead management and site-visit automation for residential property developers. [Live demo](https://real-estate-phi-lemon.vercel.app)

- Captures every enquiry in one place and replies instantly in English, Hindi or Gujarati.
- Answers only from an approved fact sheet, and hands price negotiations to a named salesperson with the full chat history.
- Books site visits into real free slots, with role-based dashboards for admins, sales heads and executives.
- Respects buyer opt-out and flags duplicate leads for review instead of merging them automatically.
- **Stack:** Python, TypeScript, REST API, PostgreSQL, FastAPI
